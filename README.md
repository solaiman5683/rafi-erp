# Jomoddar Traders · জমাদ্দার ট্রেডার্স

নবাবপুরের হার্ডওয়্যার দোকান জমাদ্দার ট্রেডার্সের জন্য স্টক, বিক্রি, বাকি (credit), ক্রয়, খরচ ও পুরো হিসাবের সফটওয়্যার।
ইন্টারনেট বা বিদ্যুৎ না থাকলেও কাজ চলে — সব এন্ট্রি আগে ডিভাইসে সেভ হয়, নেট এলে নিজে থেকে Cloudflare-এ সিঙ্ক হয়।

## যা যা আছে

| মেনু | কাজ |
|---|---|
| হোম | আজকের বিক্রি/লাভ/খরচ, পাওনা-দেনা, ক্যাশ, কম স্টক, ১৪ দিনের চার্ট, বড় বড় শর্টকাট বাটন |
| বিক্রি করুন (POS) | পণ্যে চাপ দিয়ে কার্টে যোগ, সাইজ/ভ্যারিয়েন্ট বাছাই, প্রতি লাইনে ও পুরো বিলে ছাড় — **% / টাকা / বিক্রি দাম** যেকোনো একটা লিখলে বাকিগুলো নিজে হিসাব হয়, কাস্টমারের নিয়মিত ছাড় ও পাইকারি দাম নিজে বসে, আংশিক টাকা দিলে বাকি খাতায় যায়, কার্ট ড্রাফট সেভ থাকে (বিদ্যুৎ গেলেও হারায় না) |
| বিক্রির খাতা | সব মেমো, প্রিন্ট (A4/A5), মাল ফেরত |
| মাল কেনা | সাপ্লায়ার থেকে নগদ/বাকিতে ক্রয়, গড় কেনা দাম (weighted average) নিজে আপডেট, নতুন বিক্রি দাম বসানো, ক্রয় বাতিল |
| পণ্য ও স্টক | ক্যাটাগরি, ব্র্যান্ড, একক (পিস/কেজি/ফুট/গজ/কয়েল…), অনেক সাইজ একসাথে (`½", ¾", 1"`), খুচরা ও পাইকারি দাম, কম স্টক সতর্কতা, বারকোড/কোড, স্টক গণনা ঠিক করা |
| কাস্টমার ও বাকি | কাস্টমারের ধরন, নিয়মিত ছাড়, আগের বাকি, খাতা (চলমান ব্যালেন্স), টাকা জমা + মানি রিসিপ্ট, খাতা প্রিন্ট |
| সাপ্লায়ার | দেনা, খাতা, টাকা দেওয়া |
| খরচ | ভাড়া, বেতন, বিদ্যুৎ, ভ্যান ভাড়া, কুলি, চা-নাস্তা… বড় আইকনে চাপ দিয়ে লেখা |
| হিসাব ও রিপোর্ট | লাভ-ক্ষতি, দিনভিত্তিক বিক্রি ও লাভ, বেশি বিক্রি হওয়া মাল, স্টকের মূল্য, পাওনা/দেনা তালিকা, ক্যাশ বই, CSV ডাউনলোড |
| সেটিংস | দোকানের তথ্য (মেমোতে ছাপা হয়), ভাষা (বাংলা/English; সংখ্যা সবসময় ইংরেজিতে), ইউজার যোগ ও পিন/পাসওয়ার্ড বদলানো, সিঙ্ক, ব্যাকআপ ডাউনলোড/ফেরত |

**ইউজার:** মালিক সব দেখেন। স্টাফ শুধু বিক্রি, স্টক, কাস্টমার ও খরচ — কেনা দাম, লাভ, রিপোর্ট, ক্রয় ও সাপ্লায়ার দেখতে পায় না (সার্ভারও স্টাফের পণ্য/দাম বদলানো আটকায়)। লগইন: নাম বাছাই + পিন বা পাসওয়ার্ড (কমপক্ষে ৪ অক্ষর)। মালিক সেটিংস → ইউজার থেকে যেকোনো ইউজারের পিন/পাসওয়ার্ড বদলাতে পারেন। ৫ বার ভুল দিলে ৫ মিনিট লক।

## কীভাবে অফলাইনে কাজ করে

```
ডিভাইস (IndexedDB)  ──outbox──▶  Cloudflare Worker /api/sync/push ──▶ D1
        ▲                                                            │
        └──────────────── /api/sync/pull?since=seq ◀─────────────────┘
```

- প্রতিটি এন্ট্রি আগে ডিভাইসের IndexedDB-তে সেভ হয় এবং একটা `outbox`-এ লাইন পড়ে। নেট থাকলে ১-২ সেকেন্ডে, না থাকলে নেট ফিরলেই পাঠানো হয়।
- স্টক, বাকি ও ক্যাশ হিসাব হয় **জার্নাল** থেকে (`stock_moves`, `ledger`, `cash_moves`) — এগুলো শুধু যোগ হয়, কখনো বদলায় না। তাই দুই ডিভাইসে একসাথে অফলাইন বিক্রি হলেও হিসাবে গরমিল হয় না।
- মেমো নম্বরে ডিভাইস কোড থাকে (`K4M-0012`), তাই অফলাইনেও দুই ডিভাইসের নম্বর মিলে যায় না।
- পুরো অ্যাপ PWA — একবার খোলার পর নেট ছাড়াও খোলে। "Install / Add to Home screen" করে নিলে ব্রাউজার ডাটা স্থায়ীভাবে রাখে।
- সেটিংস → "ব্যাকআপ ফাইল নামান" দিয়ে যেকোনো সময় পুরো ডাটার JSON কপি রাখা যায়। D1-এ Cloudflare-এর Time Travel (৩০ দিন পর্যন্ত আগের অবস্থায় ফেরা) আলাদাভাবে আছে।

## লোকাল ডেভেলপমেন্ট

```bash
npm install
npm run db:migrate:local
npm run dev
```

http://localhost:5173 খুলুন। প্রথমবার "প্রথমবার সেটআপ" স্ক্রিন আসবে।
সেটিংস → "নমুনা পণ্য দিয়ে চেষ্টা করুন" চাপলে নবাবপুর-ধাঁচের কিছু নমুনা পণ্য, কাস্টমার ও সাপ্লায়ার যোগ হয়।

> লোকাল টেস্ট ডাটাবেস (`.wrangler/`, git-এ যায় না): মালিক "জমাদ্দার", পাসওয়ার্ড `Jomo#9876`। এটা শুধু এই কম্পিউটারের ডেভ ডাটা — আসল সার্ভারে আলাদা পিন দিয়ে সেটআপ করবেন।

## Cloudflare-এ ডিপ্লয়

```bash
npx wrangler login
npx wrangler d1 create rafi-erp-db
```

যে `database_id` দেখাবে সেটা `wrangler.jsonc`-এ বসান, তারপর:

```bash
npm run db:migrate:remote
npm run deploy
```

ডিপ্লয় শেষে যে `https://rafi-erp.<account>.workers.dev` লিংক আসবে, **সাথে সাথে খুলে সেটআপ শেষ করুন** (দোকানের নাম, মালিকের নাম, পিন) — যে প্রথম সেটআপ করবে সে-ই মালিক হবে।

ঐচ্ছিক:
- `npx wrangler secret put JWT_SECRET` — নিজের সিক্রেট দিতে চাইলে (না দিলে সার্ভার নিজে একটা বানিয়ে D1-এ রাখে)।
- Cloudflare ড্যাশবোর্ড → Workers → rafi-erp → Domains থেকে নিজের ডোমেইন (যেমন `erp.rafihardware.com`)।
- পরে নতুন migration যোগ হলে আবার `npm run db:migrate:remote`।

migrations/         D1 টেবিল
